# doc/

Documentation owned by the agent working on this repo. Humans edit `input/` and
`ADR/` reviews; the agent keeps this folder current.

- `reports/` One page per session: what was done, decided, and what is next.
  Named `YYYY-MM-DD-<topic>.md`.
- `notes/` Research and measurements that reports and ADRs cite. Longer than a
  report, narrower than an ADR.
