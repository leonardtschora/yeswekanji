# Session report, 2026-09-23: kick-off

Brief: `input/idea.md`. Goal of the session: take the architecture decisions for
the one-feature prototype, plan the work, and set up the repository. No app code
was written in this session, by design.

## Decisions taken (details in ADR/)

1. **Database: KANJIDIC2** (ADR 0001). Downloaded and measured: 2,066 kanji carry a
   French meaning, 1,987 of the 2,136 jōyō. Readings are in kana; romaji comes from
   `pykakasi`, tested.
2. **Lexical fields: hand-curated themes** (ADR 0002). KANJIDIC2 has no semantic
   groups. Ten themes of ten kanji as a JSON file. Embedding-based clustering later.
3. **Voice: gTTS, pre-generated** (ADR 0003). Tested today for French and
   Japanese, one second for two clips, ~12 KB each. One MP3 per kanji, French then
   Japanese, committed to the repo. No runtime TTS.
4. **Translation: none needed** (ADR 0004). French coverage is 93% of jōyō;
   themes only use covered kanji. 149 jōyō kanji lack French; fix later with an LLM
   pass if wanted.
5. **Host: Streamlit Community Cloud** (ADR 0005). Yes, it can stay on Streamlit.
   Free, deploys from this repo, sleeps after 12 h idle. Gradio/HF Spaces is the
   equivalent alternative; a static GitHub Pages site is the fastest of all and is
   the fallback if Streamlit's UI feels clunky.
6. **Audio playback: `st.audio(autoplay=True)`** (ADR 0006). Supported since
   Streamlit 1.34. Render the player only for the card just flipped.

## Answers to the brief's hosting questions

- Streamlit: yes.
- Alternatives: Gradio on Hugging Face Spaces (same effort), static GitHub Pages
  (less), NiceGUI/Reflex (more). `doc/notes/hosting-alternatives.md`.
- OVH: 2.5 to 4 h of agent work plus DNS propagation, ~4 EUR/month, ongoing ops.
  `doc/notes/ovh-path-estimate.md`. Not for the prototype.
